Software factories? Fac that.

Agents can now write more code than anyone can read. Consult has them write less of it, keep it simple, and walk you through every change, so you still know how it works. It’s built from 25 years of web app, SRE, and developer platform experience, and iterated on since the early days of coding assistants.

Every stage runs the same loop.

Coding agents were trained on finished code, not on how engineers got there. That code came out of drafts, tests, reading, and review that never made it into the repo. Consult brings that way of working back to you, just with agents to make it faster.

It plans, asks, builds, and checks.

  1. Designs the data, interfaces, and APIs with you. It asks before anything hard to undo, and gets on with the small stuff.

  2. Builds in tested stages. Data, then interfaces, then logic. Every requirement gets a test.

  3. Gets a second opinion. A fresh reviewer checks the work until it comes back clean.

  4. Keeps the code simple. Nine core rules apply to every change, from small functions to no speculative layers.

  5. Tells you what changed. So you still know how the code works.

24 skills, 9 core rules, and about 1,500 tokens of always-on text. See every skill and rule.
