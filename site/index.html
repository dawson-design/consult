Put the assistant back in coding assistant.

An open-source skills and workflow plugin for AI coding agents, built on one rule: keep software simple enough to understand, change, and test.

1/plugin marketplace add dawson-design/consult
2/plugin install consult@consult

Run each command inside Claude Code.

  1. 1Open Customize, then Plugins.

  2. 2Select Add, then Add marketplace, and enter:

    dawson-design/consult

  3. 3Find Consult and select Add. It also appears in Claude Code sessions signed in to the same account. Turn on code execution in the app’s settings so skills can run.

Already added? If Claude says a marketplace with that name exists, install Consult from the existing consult marketplace. If it shows an old version, use Check for updates or restart Claude, or remove it and add it again.

Context isn’t just for agents.

Agents can now write more code than anyone can read. One-shot a feature and you get the code without the context of how it was built. Consult builds it up with you in small, tested stages, keeps it simple, and walks you through every change, so you know how it works as it grows.

Iterate to build shared understanding.

Coding agents were trained on finished code, not on how engineers got there. Many engineers who use agents already steer them through plan, build, prove, and review by hand. Consult writes that loop into the agent’s skills, so it runs at every stage without you asking for it.

Hard-won lessons, for free.

Consult is built from 25 years of web app, SRE, and developer platform experience, with Rich Hickey’s Simple Made Easy as its north star. It gives your agent the habits and opinions that used to take years of mistakes to learn.

  1. Designs the data, interfaces, and APIs with you. It asks before anything hard to undo, and gets on with the small stuff.

  2. Builds in tested stages. Data, then interfaces, then logic. Every requirement gets a test.

  3. Gets a second opinion. A fresh reviewer checks the work until it comes back clean.

  4. Keeps the code simple. Eight core rules apply to every change, from small functions to no speculative layers.

  5. Tells you what changed. So you still know how the code works.

24 skills, 8 core rules, and about 1,500 tokens of always-on text. See every skill and rule, or read the thinking behind them.
